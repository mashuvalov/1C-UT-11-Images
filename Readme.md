# Изображение товара в подборе УТ 11

Задача: отдельным расширением добавить превью картинки выбранной номенклатуры в подбор товаров документа продажи и закупки. Картинку выводим не в строках динамического списка, а отдельным полем рядом со списком.

## 1. Создать новое расширение

В конфигураторе откройте базу УТ 11:

```text
Конфигурация -> Расширения конфигурации
```

Создайте новое расширение:

```text
Имя: Расширение_Изобаржение_Подбор
Синоним: Картинки в подборе товаров
Назначение: Адаптация
Префикс имен: Расш_Шувалов_
```

Остальные свойства оставьте типовыми для вашей базы. После создания сохраните расширение.

## 2. Заимствовать форму подбора продажи

В основной конфигурации найдите форму подбора товаров. Обычно это:

```text
Обработка.ПодборТоваровВДокументПродажи.Форма.Форма
```

Если точное имя отличается, используйте поиск по конфигурации:

```text
ПодборТоваровВДокументПродажи
```

Заимствуйте эту форму в новое расширение `Расширение_Изобаржение_Подбор`.

Для подбора закупки заимствуйте вторую форму:

```text
Обработка.ПодборТоваровВДокументЗакупки.Форма.Форма
```

Если точное имя отличается, используйте поиск по конфигурации:

```text
ПодборТоваровВДокументЗакупки
```

Дальше для формы закупки выполняются те же шаги: реквизиты формы, поле картинки, код модуля и событие `ПриАктивизацииСтроки` списка номенклатуры.

## 3. Добавить реквизиты формы

В заимствованной форме добавьте реквизиты:

| Имя | Тип |
| --- | --- |
| `Расш_Шувалов_АдресКартинкиТовара` | `Строка` |
| `Расш_Шувалов_ПоследняяНоменклатураКартинки` | `СправочникСсылка` |

Если конфигуратор дает выбрать только общий тип `СправочникСсылка` и не дает развернуть его до `СправочникСсылка.Номенклатура`, оставьте общий тип. Он подходит для хранения ссылки на номенклатуру.

## 4. Добавить поле картинки

На форму добавьте элемент:

```text
Поле картинки
```

Разместите его справа или снизу от списка подбора. У элемента картинки задайте:

```text
Данные = Расш_Шувалов_АдресКартинкиТовара
```

## 5. Вставить код в модуль формы

Код модуля формы лежит здесь:

```text
src/DataProcessors/ПодборТоваровВДокументПродажи/Forms/Форма/Ext/Form/Module.bsl
```

Перенесите процедуры и функции из этого файла в модуль заимствованной формы продажи. Для формы закупки используйте этот же код без изменений.

## 6. Привязать событие списка

На элементе списка номенклатуры найдите событие:

```text
ПриАктивизацииСтроки
```

Добавьте обработчик расширения:

```text
Расш_Шувалов_СписокПриАктивизацииСтрокиПосле
```

Тип вызова поставьте:

```text
После
```

Тип вызова лучше задавать через палитру свойств формы, а не ручной аннотацией в коде.

## 7. Проверить имя списка

В коде есть автоопределение списка:

```bsl
ПодборТоваровКлиентСервер.ИмяСпискаНоменклатурыПоВариантуПоиска(ЭтаФорма)
```

Если в вашем релизе оно не сработает, замените строку в функции `Расш_Шувалов_ПолучитьТекущуюНоменклатуруПодбора()`:

```bsl
ИмяСпискаНоменклатуры = "СписокНоменклатуры";
```

на реальное имя элемента списка на форме. Частые варианты:

```text
СписокРасширенныйПоискНоменклатура
СписокСтандартныйПоискНоменклатура
Список
РезультатыПоиска
```

## 8. Первый запуск

1. Проверьте расширение в конфигураторе.
2. Запустите базу в пользовательском режиме.
3. Откройте документ продажи и подбор товаров.
4. Встаньте на товар, у которого в карточке заполнена картинка.
5. Проверьте, что рядом со списком появилась картинка выбранного товара.

Для закупки откройте документ закупки, вызовите подбор товаров и проверьте аналогично.

## Как добавить закупку после продажи

Если подбор продажи уже работает, для закупки сделайте коротко так:

1. В этом же расширении `Расширение_Изобаржение_Подбор` заимствуйте форму `Обработка.ПодборТоваровВДокументЗакупки.Форма.Форма`.
2. Добавьте в форму закупки реквизиты `Расш_Шувалов_АдресКартинкиТовара` и `Расш_Шувалов_ПоследняяНоменклатураКартинки`.
3. Добавьте элемент `Поле картинки` с `Данные = Расш_Шувалов_АдресКартинкиТовара`.
4. Перенесите в модуль формы закупки тот же код, что уже стоит в форме продажи.
5. На списке номенклатуры формы закупки привяжите событие `ПриАктивизацииСтроки` к `Расш_Шувалов_СписокПриАктивизацииСтрокиПосле` с типом вызова `После`.
6. Сохраните расширение, выполните проверку применимости и обновите конфигурацию базы данных.
7. Полностью перезапустите пользовательский режим.

Если картинка в закупке не появляется, временно включите отладку в функциях `Расш_Шувалов_ОтладкаКартинкиПодбора()` и `Расш_Шувалов_ОтладкаКартинкиПодбораНаСервере()`, вернув `Истина`.

## Если картинка не появилась

Проверьте по порядку:

1. У товара заполнено поле `ФайлКартинки`.
2. Поле картинки на форме привязано к `Расш_Шувалов_АдресКартинкиТовара`.
3. Обработчик `Расш_Шувалов_СписокПриАктивизацииСтрокиПосле` привязан к событию `ПриАктивизацииСтроки` именно списка номенклатуры.
4. `Расш_Шувалов_ПолучитьТекущуюНоменклатуруПодбора()` возвращает ссылку на номенклатуру.
5. `РаботаСФайлами.ДанныеФайла(...)` возвращает непустую `СсылкаНаДвоичныеДанныеФайла`.

Серверная функция сделана с контекстом формы (`&НаСервере`), чтобы использовать `ЭтаФорма.УникальныйИдентификатор` при получении адреса двоичных данных.

## Отладка

В модуле формы включены временные диагностические сообщения с префиксом:

```text
[КартинкаПодбора]
```

Если сообщения мешают после настройки, отключите их в функции:

```bsl
Функция Расш_Шувалов_ОтладкаКартинкиПодбора()

	Возврат Ложь;

КонецФункции
```

Серверные диагностические сообщения отключаются отдельно:

```bsl
Функция Расш_Шувалов_ОтладкаКартинкиПодбораНаСервере()

	Возврат Ложь;

КонецФункции
```

## Оформление картинки

Если картинка появилась узкой полосой, увеличьте высоту элемента `Расш_Шувалов_КартинкаТовара`. Для нижнего расположения удобно начать с высоты 120-180. Для бокового расположения задайте ширину примерно 180-260 и высоту 180-260.

В свойствах поля картинки, если такие свойства доступны в вашем релизе, используйте пропорциональное масштабирование изображения и не растягивайте картинку без сохранения пропорций.

Для элемента `Расш_Шувалов_КартинкаТовара` обычно нужно свойство:

```text
Оформление -> РазмерКартинки = Пропорционально
```

Если такого свойства не видно, используйте поиск по свойствам по строке `РазмерКартинки` или `Размер картинки`.

Если тестовая надпись не появляется в пользовательском режиме:

1. Сохраните расширение в конфигураторе.
2. Выполните `Конфигурация -> Обновить конфигурацию базы данных`.
3. Проверьте в списке расширений, что `Расширение_Изобаржение_Подбор` активно и используется.
4. Полностью закройте пользовательский режим и откройте заново.
5. Для проверки добавьте простую надпись прямо в корень формы или в заведомо видимую верхнюю группу, а не внутрь скрываемых групп подбора.
