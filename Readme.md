# Изображение товара в подборе УТ 11

Расширение добавляет превью картинки выбранной номенклатуры в форму подбора товаров в документ продажи. Картинка не встраивается в каждую строку динамического списка: обновляется только отдельное поле картинки для текущей строки, через обработчик ожидания.

## Где менять форму

В расширении заимствуйте форму подбора товаров. В типовых релизах УТ 11 это обычно:

```text
Обработка.ПодборТоваровВДокументПродажи.Форма.Форма
```

Если имя отличается, найдите объект в конфигураторе по строке:

```text
ПодборТоваровВДокументПродажи
```

## Реквизиты формы

Добавьте в заимствованную форму реквизиты:

| Имя | Тип |
| --- | --- |
| `Расш_Шувалов_АдресКартинкиТовара` | `Строка` |
| `Расш_Шувалов_ПоследняяНоменклатураКартинки` | `СправочникСсылка.Номенклатура` |

## Элемент формы

Добавьте элемент формы `Поле картинки`, разместите его справа или снизу от списка подбора.

У элемента картинки задайте:

```text
Данные = Расш_Шувалов_АдресКартинкиТовара
```

## Код формы

Код модуля формы расширения находится здесь:

```text
src/DataProcessors/ПодборТоваровВДокументПродажи/Forms/Форма/Ext/Form/Module.bsl
```

Перенесите процедуры и функции из этого файла в модуль заимствованной формы.

## Привязка события

На элементе списка номенклатуры найдите событие:

```text
ПриАктивизацииСтроки
```

Добавьте обработчик расширения с типом вызова `После`:

```text
Расш_Шувалов_СписокПриАктивизацииСтрокиПосле
```

Для событий формы в расширении надежнее задавать тип вызова через палитру свойств формы, а не ручной аннотацией в коде.

## Если список называется иначе

В коде есть автоопределение списка через:

```bsl
ПодборТоваровКлиентСервер.ИмяСпискаНоменклатурыПоВариантуПоиска(ЭтаФорма)
```

Если в вашем релизе метод недоступен или форма устроена иначе, замените значение по умолчанию в `Расш_Шувалов_ПолучитьТекущуюНоменклатуруПодбора()`:

```bsl
ИмяСпискаНоменклатуры = "СписокНоменклатуры";
```

На реальное имя элемента списка, например `Список`, `РезультатыПоиска` или другое имя из формы.

## Проверка

1. У товара в карточке заполнено поле `ФайлКартинки`.
2. Элемент картинки привязан к `Расш_Шувалов_АдресКартинкиТовара`.
3. Событие `ПриАктивизацииСтроки` привязано именно к списку номенклатуры.
4. `Расш_Шувалов_ПолучитьТекущуюНоменклатуруПодбора()` возвращает ссылку на `СправочникСсылка.Номенклатура`.
5. `ПрисоединенныеФайлы.ПолучитьДанныеФайла(...)` возвращает непустую `СсылкаНаДвоичныеДанныеФайла`.

Серверная функция сделана с контекстом формы (`&НаСервере`), чтобы использовать `ЭтаФорма.УникальныйИдентификатор` при получении адреса двоичных данных.

## Что видно по отчету

`ОтчетПоКонфигурацииУТ11.txt` показывает текущее расширение `Расширение_Комментарий_ЧекККМ` с префиксом имен `Расш_Шувалов_`. Поэтому реквизиты и обработчики в этой заготовке названы с этим префиксом.

Форма подбора товаров в отчете пока не заимствована. Сейчас в расширении есть заимствованные объекты `Документы.ЧекККМ`, `Документы.ЗаказКлиента`, `ЖурналыДокументов.ЧекиККМ` и связанные формы, но нет `Обработка.ПодборТоваровВДокументПродажи.Форма.Форма`. Ее нужно добавить в расширение перед переносом кода.
